# v0.4.0 完善版：需求差异与完成实况

构建标识：v0.4.0-completion.1。基线为已发布的 v0.4.0，原发布 ZIP 保留不变；本次是增量实现，不是重建应用。

| 用户要求 | 当前状态 | 实现与边界 |
|---|---|---|
| 10/20/30 分钟冷落 | 实际完成 | 单调时钟记录清醒无互动时间，600/1200/1800 秒依次寻找、轻微委屈、生闷气；按截止点设置单次计时器，不每秒轮询。 |
| 游戏期间暂停累计 | 实际完成 | enter_sleep 冻结时钟，只有手动唤醒才续计；重启保存已累计秒数，不计关机/离线时间。休眠时停止所有性格/动画/梦话计时器。 |
| 生气的四类动作 | 实际完成，初版美术 | 原鼓脸帧 + 新背身、抱尾、回头各 4 帧。每段播完保持姿态，约 8 秒换一次；无持续气泡轰炸。 |
| 四次独立摸摸 | 实际完成 | 独立 InteractionClock.touch 状态机：1 仍生气、2 心软、3 蹭鼠标、4 原谅。需猫身上独立按下/释放且相邻有效触摸至少 0.65 秒。快速连点、拖动、空白、忙碌和游戏时的点击不计数。 |
| 不用三连击代替安抚 | 实际完成 | 生气分支优先于原 1.2 秒三连击；三连击只保留给正常开心互动。聊天、跳过、隐藏、造型切换不会直接原谅，关闭冷落功能则由用户主动清除生气状态。 |

| 打瞌睡 | 实际完成，独立 4 帧 | 坐着垂眼、点头；结束转入蜷睡。 |

| 玩游戏机 | 实际完成，独立 4 帧 | 手持游戏机、按键/歪头，佩戴圆形金丝眼镜。 |
| 洗脸 | 实际完成，独立 4 帧 | 舔爪、擦左/右脸。 |

## 素材计数

保留原 60 张 WebP；新增七类日常 28 张、迎接 4 张、三类生气 12 张、心软/蹭鼠标 8 张，共新增 52 张，总计 112 张独立帧。七类日常不引用任何重逢文件；52 张新图均经真实 Qt 解码/透明通道检查，示例渲染见 previews/lifestyle-v0.4.0-completion-linux.png。

本轮七项日常和启动/情绪动作**无整组缺失素材**。尚缺的是更密集的中间帧、专业清边和风格统一修型；不会将这些美术润色标为已经完成。

## 仍保留的原有差距

- Windows GUI EXE、本轮 Windows 11 / HyperX / GPU / 游戏并行体验尚未验证；只交付源码与已有构建脚本。
- 原“敲咪”唤醒仍是可替换的实验性 ASR 识别方案，默认关闭，不是已验证的专用中文 KWS。本次没有把它改名充作专用唤醒。
- 普通中文 ASR/TTS/Ollama/长期记忆继续保留。自动化含模拟设备/模型，不能代替真实模型与麦克风测试。
- 工作造型原有素材及部分重逢/主动撒娇复用关系未全部重绘，旧素材粉色半透明边缘等问题仍见 ASSETS_V0.4.0.md。
- 游戏深眠不终止独立共享的 Ollama 服务，已发出的服务端计算不保证立即停止；不会在深眠中发起新推理。

## 数据与设置

仅扩展 personality.json 字段：开关 neglect_enabled/daily_enabled/dream_enabled/welcome_enabled，运行快照 neglect_elapsed/sulking/soothe_count。原字段与未知字段保留；SQLite、主配置、语音配置、desktop.json schema 均不变。原 audio_capture.py、voice_worker.py、storage.py 字节保持。无 SQL 迁移。

“主动撒娇与日常”是总开关，自动日常另有子开关；手动日常仍可从右键“敲咪的日常生活”或性格设置选用。工作/游戏眼镜造型暂停自动撒娇/日常和冷落动作展示，但保留冷落时钟；真正的游戏深度休眠才冻结时钟。关闭冷落可解除生气；默认不会要求用户必须陪伴才能正常聊天。
