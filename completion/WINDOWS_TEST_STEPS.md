# Windows 11 v0.4.0 手动验收（待实际执行）

本次环境为 Linux + Qt offscreen；以下均为待验证，不代表 Windows 11、HyperX 或游戏真机通过。先备份原数据，在新的项目目录/隔离数据目录试运行。

1. start.bat 安装依赖；双击 start.vbs / 桌面“敲咪”，确认无短暂黑窗、只有猫与托盘，中文聊天、记忆查看/确认/改删/导出正常。
2. 拖动猫后退出重启，位置、形象和长期记忆不丢。关闭聊天 X 保留猫与托盘；双击猫恢复聊天。
3. 托盘进入“性格与形象”，选择工作、游戏造型，分别确认圆形金丝眼镜、电脑/手柄。选择陪伴恢复普通形象。
4. 开启游戏深度休眠，猫消失，语音停止；任务管理器检查无语音工作进程、无重复实例。静待、切换游戏、再开快捷方式、重启 App 均不得自动唤醒。
5. 明确点“唤醒敲咪”：揉眼→惊喜→泪眼→迈步→求抱→短暂依偎；出现核心台词。只播放一次，不弹主聊天、不抢焦点、不强制播音。动画中可跳过。
6. 撒娇期间点头闭眼、点肉垫缩爪、快速连点三次打滚；不互动则短暂鼓脸后恢复，哭泣不得无限循环。
7. 关闭重逢再休眠/唤醒，不播放重逢；关闭主动撒娇，等超过自定义间隔仍不主动。关闭气泡则动作仍可播放但无撒娇文字。
8. 正常模式选择自定义 60 秒间隔，检查动作不连续刷屏、不夺焦点；隐藏猫、忙于识别/聊天或选择眼镜造型时停止主动行为。
9. HyperX QuadCast S 选择 Windows WASAPI：测试麦克风音量/诊断，手动开始→结束并识别，CPU int8 中文识别/TTS/打断；休眠期间按钮禁用，唤醒后手动功能恢复，持续唤醒保持关闭。
10. 选择旧自定义形象，确认可用；缺重逢资源明确提示、跳过，不只用随机文字假装动画。测试资源损坏提示/log，无无声退出。
11. 重复双击快捷方式单实例；托盘隐藏/显示、Explorer 重启恢复、自启动开关可逆；完全退出释放麦克风、语音进程、数据库和托盘。
12. Windows 构建完整 onedir，确认 WebP/Qt 插件可用、全部 assets/personality 被打包；新机器/重启后读取原持久目录，ZIP 无模型/私人数据。
13. APEX/幻兽帕鲁前手动休眠，用任务管理器或 scripts/measure_idle.py 记录 CPU/RSS/GPU，比较正常与休眠。不能从 Linux 结果推断 Windows 游戏影响为零。

需记录系统/Python/Qt/模型版本、设备接口、DPI、截图、voice.log 与性能 JSON；不要公开私人语音或记忆。

## 完善版新增验收（未在 Windows 实机执行）

14. 手动普通启动：左边缘探头→眨眼→挥爪→跳出，结束恢复原位置。跳过/发送聊天/拖动中断均无位置丢失、不抢焦点。登录自启动/深眠重启/重复激活不迎接；手动唤醒只重逢。
15. 临时数据正常陪伴，实际静待10/20/30分钟检查寻找/委屈/生闷气；应看到鼓脸/背身/抱尾/回头，不连续弹气泡。自动动作不重置计时，真实聊天/触摸会重置。
16. 生气后先快速三连点，应不能原谅；再以至少0.65秒间隔独立触摸，依次观察第一下仍气、第二下心软、第三下蹭鼠标、第四下原谅；检查系统光标没有被移动。拖动、空白点击不计数。聊天/跳过/隐藏/造型变化不冒充第四次。
17. 累计约9分钟后进入游戏深眠，等待一段时间，检查全部动画/生活计时器停且无梦话，手动唤醒后继续剩余约1分钟，不将游戏时间计入冷落。部分安抚后深眠/重启再恢复，应保留次数。
18. 逐个手动选择七个日常动作，辨认食盆、点头、侧卧蜷身、金丝眼镜手柄、洗脸、四足前伸、毛线球；不应只换气泡。打瞌睡结束转蜷睡。
19. 普通睡觉实际静待3–7分钟，观察低频梦话文字无语音；醒来/繁忙/隐藏/关闭开关/深眠停止。不要将加速测试当成真实分钟级耐久测试。
20. 关闭冷落/自动日常/梦话/迎接开关，退出重启确认保存。独立长期记忆/聊天/HyperX语音回归；素材不足的自定义形象要明确提示，不用重逢帧冒充日常。
