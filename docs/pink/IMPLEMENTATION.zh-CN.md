# QIAOMI AI v0.5.0-pink.1 — 粉色管家整合候选

## 基线与需求边界

本次在上一轮已交付的v0.5.0-life.1源码上增量修改，保留项目结构。上传的新ZIP超过当前附件读取工具32 MiB上限，未能逐项核对其内是否有额外需求文档或未公开的新实现。因此本轮按本次消息中列出的九项目标、图片和后续三条纠正实施；**不能声称已完整验收尚未读取的“整合包完整需求书”**。请将该文档单独提供后再做最终差异核对。

已检查的基线里只有独立生活面板、原洗脸动作与程序澡盆/泡泡，并没有精致洗澡、脱睡衣或浴巾素材；没有覆盖任何已有脱衣实现。基线ZIP留存在开发工作区；无法读取用户Windows磁盘。新版首次运行在数据目录内额外备份现有JSON/SQLite（含已提交WAL），使用独立升级标记，备份失败停止启动，不迁移数据库。

## 实际实现

- 主窗口新增管家首页与“照顾敲咪”，内含照顾概览、洗澡澡、喂饭饭；聊天、记忆和设置仍保留原索引/控制器，导航全部可用。托盘生活入口现在打开主窗口照顾页。
- 新增粉色主题，作为**新用户默认**；保留用户已有浅/深主题设置，不擅自覆写个人配置。设置可随时选择三个主题和原四档字体。
- 洗澡：脱睡衣/入浴→搓泡泡→冲洗→浴巾/吹干→恢复睡衣。最后阶段补充四个独立关键帧：连体衣穿上→拉好拉链→戴帽→完整穿好开心展示；结束保持完整穿好的形象。
- 手动搓泡泡显示拿海绵的成年女性手部，页面内跟随鼠标；按住拖动或点击部位清洗，部位按钮也可用。自动洗和一键洗不显示人手。手部不是系统鼠标替换，不使用全局钩子，也不覆盖其他应用。
- 喂食：小鱼干捧食/咀嚼和猫饭低头/舔嘴有独立新关键帧及粉色场景。手动模式三次独立喂一口（间隔≥0.35秒），再进入收尾；自动按时序播放，一键即时数值到100。无额外库存/付费消耗。
- 所有新页面和桌宠共用CareEngine，重复点击不叠加活动；手动/自动/一键、暂停/继续、下一步、跳过完成、取消/超时均通过同一个状态机。洗澡最后完成才加清洁，非一键中途取消不加奖励；一键已生效的数值不会因取消短动画而撤回。
- 新素材所有可见完整穿衣阶段的胸饰改为红上白下、黑中线的宝可梦球，不是铃铛。裸身/浴巾阶段没有胸饰。

## 性能与深眠

场景资源懒加载，共享LRU缓存上限28,000,000字节（约26.7 MiB）；普通隐藏页面无刷新计时器，可见且有活动时场景以80ms间隔刷新。进度复用该计时器，不另增轮询；停止后静态保持。生活数值仍沿用5秒调度与原保存节流。

游戏模式/系统睡眠/退出会停止新场景计时器、收起活动、清空新场景缓存，原动画/语音/AI深眠逻辑保留。游戏状态下查看页面仅显示休眠提示，不解码场景，不唤醒推理/麦克风；只能托盘明确唤醒。恢复不补播旧洗澡/喂食。

## 美术完成范围和限制

新增`assets/butler/`：三个粉色房间背景（浴室、餐厅、空前景起居室）、12格照顾关键帧图集、4格完整穿衣收尾图集、女性海绵手部。实际渲染只使用所需背景，旧图集/图标未替换。

这些是**独立关键帧＋程序微动/局部效果的动画**，不是逐帧完整3D脱衣模拟，阶段切换和少量透明边缘仍需用户视觉审核。未把静态设计图当作运行截图。浴缸前景通过场景真实浴缸遮挡图层重绘实现，不在猫图里画假边框。

原257个资源全部保留，包括原桌宠、图标和已有互动动画。核查发现旧桌宠部分帧原本就带金色饰品；本轮新图集及主窗口新展示已改宝可梦球，但**尚未完成原252张WebP中历史胸饰的逐帧统一**。为避免改坏原动画/身体命中，没有用模糊覆盖或通用圆点批量盖住旧胸饰；这项不能标为全套完成。睡衣造型一致性/饰品在全部旧动作中的统一仍需专项补修。

## 安装与构建

先旧托盘完全退出，保留用户目录、模型和旧安装，将本包解压至新的可写目录。Windows11 x64/Python3.12，首次`start.bat`，语音`install_voice.bat`，日常`start.vbs`或重新运行`install_shortcut.vbs`。换目录须重建快捷方式，关闭再开启自启动以更新路径。

数据位置仍是`%LOCALAPPDATA%\QIAOMI AI`或原`QIAOMI_DATA_DIR`。新增`.upgrade-v0.5.0-pink.json`升级标记；生活数据life.json和记忆qiaomi.db保持原位置与结构。不要复制或公开数据备份。

当前执行环境Linux，**没有Windows运行环境，不生成/假称生成EXE**。原`build_windows.bat`与windowed PyInstaller配置完整保留，自动收集qiaomi模块和assets，包括新页面与场景。需在Windows构建后分发完整dist文件夹，并执行原无黑窗/语音/托盘/单实例实机验收。
