# QIAOMI AI v0.5.0 — 零负担自主生活

基于现有 v0.4.1-costume-tail.2 增量升级。保留粉色向尾喵睡衣橘猫、图标、互动、四次摸摸、长期记忆、语音、托盘、游戏深眠和主题。全部257个原资源文件未改动。

新增手动/一键/自主喂食，五阶段洗澡，逗猫棒/毛线球/玩具老鼠，3–5分钟闲置摸鱼，饱腹/清洁/精力/心情及免费自主照顾。数值仅娱乐，不会病死、不离线扣分。游戏中全部暂停，只能从托盘手动唤醒。

## 下载包与启动

本包为完整源码，**没有已构建Windows EXE**。Windows11/Python3.12，先托盘退出旧版，解压到新目录，首次运行`start.bat`准备依赖；语音运行`install_voice.bat`。日常用`start.vbs`或`install_shortcut.vbs`创建的桌面图标。换目录后重建快捷方式，并关闭/重新开启自启动以更新路径。

用户目录不变，首次升级先备份配置和SQLite（含WAL），生活值新增到独立life.json，不改原数据库结构。备份失败则停止升级。不要删除旧模型或复制旧虚拟环境。
