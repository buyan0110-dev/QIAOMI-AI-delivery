# v0.5.0-pink.2 — 比例、窗口圆角与浴缸层次修复

日期：2026-11-14（北京时间）。基于pink.1增量修改，仅修正显示/布局；生活、记忆、语音、托盘、游戏状态机未改。

## 已确认原因

1. `CareScene.cat_rect`对所有图集帧都返回正方形，但完整穿衣图集单帧为543×724。强制画入正方形使角色横向变宽。小手、背景及头像的部分位置也有固定比例/尺寸假设。
2. 原整个shell处于一个滚动区域。内容高度超过窗口时，外框底部及其圆角被滚动视口裁掉；滚动条/背景占据外沿，形成一半方、一半圆。
3. 隐藏页面的布局以及流程栏的“偏好高度”会撑高当前页，小窗口的场景把操作区挤到看不见的位置。
4. 浴缸前景仅在活动的部分阶段绘制，未开始洗澡和完整穿衣完成时，猫咪的脚爪/尾巴被画到了浴缸外壁前面。

## 实际代码修复

- 新增`ui/geometry.py`，统一等比contain与坐标变换。背景完整放进1536×1024场景，再统一等比适配到视口；不拉伸、不裁切背景冒充缩放，必要时留同主题底色边。角色按每帧真实宽高比适配，母亲手部也使用实际素材比例。全16帧均做比例和边界测试，原图片未重采样/修改。
- 指针命中与海绵跟随使用同一逆变换，窗口变化后仍与身体位置对应。小图预览省略气泡遮挡，活动文字移到进度条，避免泡泡盖住小猫脸。
- 外层固定圆角shell，使用随窗口尺寸更新的四角遮罩；透明顶层背景，页面滚动区域移到主内容内部。标题/关闭/退出与侧栏不再跟随页面滚动。
- 页面布局只测量当前可见页，场景允许在实际最小高度内缩小。标准1080×780/100%下首页、概览、洗澡、喂食均可完整显示，无主页面纵向/横向滚动。更小窗口/更大字号保留**内容区域**滚动，不截掉外框及系统管理按钮。流程栏可单独滚动，避免挤走下方操作。
- 所有洗澡画面（含未开始、脱衣、泡泡、冲洗、浴巾、穿衣、完成）最后重绘同一浴缸前景，猫咪下半身位于浴缸后方。没有添加假矩形遮挡、额外猫爪或另一条尾巴。手持海绵是正常前景交互道具。
- 头像按48×48控件实际尺寸等比缩小，避免72像素图被48像素控件截掉。窄窗下拉导航同步实际页面名称。

## 右上角按钮

按新参考改为横排最小化/最大化或还原/关闭三按钮，保留原粉色窗口底，细灰线；最大化后显示重叠方框，正常窗口显示最大化方框。支持真正最小化和还原。关闭仍只隐藏管家，不退出桌宠/托盘；完全退出使用托盘。原装饰圆环移到连接状态栏，不再混在窗口按钮中。最小化活动页面时场景计时器停止，恢复再继续，不触发游戏唤醒。

## 保留范围

全部264个pink.1运行资源（含原257资源及新增场景图/清单）逐字节不变；红白宝可梦球、女性手部、穿衣四帧均保留。无新依赖，无数据库/配置结构变动，无新后台定时器/模型。游戏深眠不解码新场景，定时器与清缓存规则保留。

更改：`qiaomi/ui/assistant.py`、`qiaomi/ui/butler.py`、`qiaomi/__init__.py`（构建号pink.2）。新增：`qiaomi/ui/geometry.py`、`qiaomi/ui/window_shell.py`。测试新增`tests/test_pink_geometry.py`；原手部测试改为使用实际控件中心坐标，适应小窗口的新尺寸，而非指向控件外。

## 验证与限制

实际Qt抓图位于previews。包含1080×780、900×700、1280×800、1500×1040标准字号，以及1080×780的150%字号；各帧比例、四角透明度、内容滚动范围原始记录在previews/geometry.json。各主题/尺寸的四个角均验证透明，页面滚动不改变外框。

浴缸测试直接比较绘制后前壁区域的像素与原浴缸背景对应像素，在未开始、全部五阶段、完成状态均不会被猫爪/尾巴盖住；不是只检查图片格式。

本环境Linux/Qt offscreen，未做Windows11/DWM/多屏/DPI实机测试。旧版美术胸饰逐帧统一、完整独立需求书核对等pink.1未完成项并未借本次显示修复标为完成。此版本仍为候选源码，没有新构建EXE。

## 启动与Windows验收

先旧托盘完全退出，再解压新目录，保留原数据/模型。首次start.bat，日常start.vbs或重新创建快捷方式；换目录后更新自启动路径。Windows EXE仍由原build_windows.bat在Windows构建。

请在Windows把窗口调为截图所用大小，依次进入首页/概览/洗澡/喂食；确认脸型不变宽、完整角色不被拉长、四角始终圆角、外框随滚动不动。洗澡全部阶段观察浴缸前壁应盖住下半身；手动海绵仍在上层。再试150%字号、缩小窗口后滚动到操作区，确认关闭/托盘退出仍可操作。游戏深眠后无新刷新；长期记忆、语音和旧互动按原验收步骤回归。
