# 源码包范围

所有Python代码、自动化测试、Windows启动/构建脚本、依赖、264个运行资源完整保留。没有用户配置、记忆数据库、录音、模型、虚拟环境、运行日志或数据备份。Windows EXE未在本Linux环境构建。

为避免反复下载大体积历史媒体，本源码ZIP省略历史docs/artfix、costume-tail、refinement2、previews、pink/previews、v050/previews的图片/视频。它们不是运行资源，在各旧交付分支仍保留。当前pink2预览仅随ZIP附1080×780标准字号的首页/概览/洗澡/喂食、手动操作、洗澡阶段、完成和标题按钮；其余字号/窗口尺寸截图在新交付分支网页查看。全部尺寸的原始几何记录geometry.json随包提供。

资产原图没有压缩、裁切、重绘或替换；ZIP压缩为无损存储压缩，不改变解压后的图片内容。
