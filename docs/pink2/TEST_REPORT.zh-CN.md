# v0.5.0-pink.2 测试报告

2026-11-14（北京时间）。Linux / Python3.12 / PySide6 6.8.3 / Qt offscreen，托盘可用性模拟，无真实录音/模型/游戏。

**完整回归：578 passed，223.36秒。** 原始输出tests.txt及JUnit tests.xml。原486项＋新增几何/层次/窗口87项＋标题按钮5项全部通过。

命令：`QT_QPA_PLATFORM=offscreen python -m pytest -q --junitxml=docs/pink2/tests.xml`。Windows去掉offscreen变量运行，但不能以Linux结果替代Windows实机。

## 实际验证

- 16个照顾/穿衣帧×4个窗口比例，目标宽高比等于帧自身宽高比；整帧与完整背景在视口内。
- 浴缸待机、五阶段与完成共7种状态，前壁区域实际像素与背景对应像素一致，猫咪脚爪/尾巴不遮住前壁。女性手部作为正常前景道具仍显示。
- 粉/浅/深三主题×3种窗口大小，四角透明、遮罩覆盖整个窗口；滚动不移动外框，标题/退出按钮不在滚动区域中。
- 1080×780/100%下首页、洗澡、喂食无主页面横向/纵向滚动；概览实际抓图也无滚动。小窗口/大字号可内容滚动，按钮仍可到达。
- 标题三按钮顺序、粉色底保留/图标绘制、最大化/还原图标切换、真正最小化、关闭只隐藏、最小化场景停止刷新均真实Qt点击验证。
- 264个运行资源与pink.1逐字节相同；所有有意变更的代码哈希登记，旧语音/记忆/生命周期回归保留。
- 游戏中调用场景几何和实际抓图均不解码场景、没有场景刷新；原深眠/手动唤醒测试保留。

初轮专项173通过、1失败：原手部测试用固定(150,160)坐标，适配后已落在较小控件外，未产生Qt鼠标移动。改用实际控件中心，仍验证真实事件跟随与手部解码；单独重测通过，最终全量通过。前一次573项全量通过后补上标题按钮测试，该578项包含上述功能修改；随后用户要求标题按钮继续使用粉色底，仅将默认背景改为透明继承窗口底色，并重跑标题按钮与全部几何/圆角/浴缸专项，结果见final-caption-tests.txt。
