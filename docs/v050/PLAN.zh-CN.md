# v0.5.0 增量开发记录

基线：现有 v0.4.1-costume-tail.2（404项原测试）。开发环境：Linux/Python 3.12/PySide6 6.8.3；日期2026-11-13（北京时间）。

## 开发前分析

- Controller统一拥有宠物、托盘、对话、记忆、语音、游戏模式和外观设置。
- PersonalityEngine已有自主日常、冷落、四次摸摸、重逢；PetWindow已有单角色渲染、透明窗口和身体命中区域。
- Store已有SQLite长期记忆；配置分文件保存在用户目录。语音是独立子进程，当前可靠的CPU int8/WASAPI路径应保持原样。
- 游戏深眠由原状态机停止动画/语音/性格任务、清缓存；新增调度必须接入同一生命周期。
- 基线完整源码及关键文件哈希已在开发工作区留存。无法读取用户Windows磁盘，因此不能声称已备份用户电脑上的记忆；本版本首次在该电脑启动时会先做安全快照。

## 实施顺序（均已落实到代码）

1. 先加首次升级备份，再加独立life.json、验证/原子保存及不离线扣分。
2. 加单活动生活协调器，接入原性格中断、触摸、拖动、任务与休眠优先级。
3. 加喂食、洗澡、玩具、自主生活与面板；复用原动画，局部绘制道具占位；不改原图。
4. 加单元/真实Qt测试、原功能回归、界面截图、短时资源采样；据结果修复，再打包。

未重构语音、AI、存储及Windows启动模块；无新增依赖，无新模型下载，无新增云服务。
