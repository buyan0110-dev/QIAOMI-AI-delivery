# QIAOMI AI v0.4.1 — 桌宠生命系统 2.0 / AI 管家界面 2.0

基于已发布 v0.4.0 完善版增量开发，保留旧源文件、数据目录、SQLite 结构、语音采集算法、Ollama 传输、无控制台入口、托盘/自启动/单实例和粉色睡衣橘猫图标。**当前交付为源码和 Windows 构建脚本，没有已构建 EXE；Windows 11 真机尚未验收。**

## 新增体验

- 四边独立栖息姿势，拖动到工作区边缘约 32 个 Qt 逻辑像素内吸附；拖离解除，可在桌面设置关闭吸附。工作区不包含 Windows 任务栏，用户位置单独保存；多屏/分辨率变更有重新夹回可见区域逻辑。
- 十个身体区域：左右耳、头、下巴、肚子、左右前爪、左右后爪和尾巴；有独立关键帧反馈。连续摸耳会缩脖、垂耳；揉肚子会捂肚皮。命中优先级及可见姿态配置见功能实况。
- 自主看书翻页、戴金丝眼镜玩游戏、毛线球、吃饭、瞌睡/惊醒/再瞌睡、趴睡、洗脸整理帽子和伸展。触摸会中断动作，经过合书/放游戏机/舔嘴/坐起等收尾 → 基础坐姿 → 部位反馈；用户触摸优先于任务的视觉提示，不取消聊天/录音数据任务。
- 冷落 10/20/30 分钟。**本版本运行期间仅有效鼠标触摸重置摸摸时钟，文字聊天、语音和拖动不再重置；明确手动唤醒后的重逢结束按需求重新起算。** 30 分钟后可从边缘爬到中央生气，每次生气最多一次；前台全屏、安全桌面或未知状态下推迟，不高频重试。不抢焦点、不移动系统光标、不模拟输入。
- 四次独立有效摸摸，相隔至少 0.65 秒：鼓脸 → 心软 → 蹭鼠标 → 专属转身举爪和好。原正常三连击不代替安抚。中央位置为临时位置，不覆盖手动保存的边缘偏好。
- 游戏深眠停止动画、爬行、冷落/梦话/自主计时、麦克风/语音进程与新推理，释放动画缓存；状态跨重启保留，只有明确“🐾 唤醒敲咪”恢复。手动唤醒后纸盒醒来、哭唧唧重逢一次，可跳过，不强制语音。
- 管家奶白浅色/原深蓝深色，100/110/125/150% 四档字体；设置→外观立即应用并保存。大字体窄窗口切为紧凑导航，可纵向滚动，不用重启桌宠。
- 欢迎区域与聊天头像使用同一敲咪图标；打开窗口时随机一句本地欢迎语，可关闭、无后台刷新。聊天增加字号/气泡间距/输入区，安全显示可复制代码块和长行；隐藏后延迟 HTML 排版，重新显示时恢复。

## 安装与启动

1. 从旧托盘完全退出；备份 `%LOCALAPPDATA%\QIAOMI AI`（或既有 `QIAOMI_DATA_DIR`）。保留旧 `models` 和自定义形象目录。
2. 解压本次完整源码 ZIP 到新的可写目录。Windows 11 x64 / Python 3.12，运行 `start.bat` 准备基础依赖，语音用 `install_voice.bat`。不要跨目录复制旧 `.venv`。
3. 日常双击 `start.vbs`，或运行 `install_shortcut.vbs` 创建桌面“敲咪”。`start.bat` 仍是带控制台的调试入口。源码 GUI 使用同一虚拟环境的 pythonw。
4. 模型继续选择原 faster-whisper-small 的完整绝对路径、CPU int8；Ollama/Qwen 和语音模型不打包。语音设置保留此前已可用的 HyperX / Windows WASAPI 配置。
5. 旧 EXE 不会随源码自动升级。要 EXE，需在 Windows 运行 `build_windows.bat`，分发完整 `dist/QIAOMI-AI`，不能只复制单个 EXE。步骤见 [构建说明](docs/WINDOWS_RELEASE.md)。

聊天 X 隐藏窗口，托盘继续运行；“退出敲咪”才释放资源并结束。开机自启动默认关闭、HKCU 用户级、无管理员权限。重复启动通过原本地 IPC 激活现有实例，不重复加载模型。

## 设置与兼容

- 偏好设置→外观：主题、字体、欢迎语。保存到新 `appearance.json`，不覆盖原配置文件。
- 托盘→桌面与启动设置：吸附开关、原自启动、形象选择。新增 `desktop.json` 的 edge/snap_enabled/screen_name；原 position/形象与未知字段保留。
- 托盘→性格与形象：主动撒娇/日常总开关、频率、冷落/梦话/迎接/中央寻找开关，以及手动日常动作预览。工作/游戏造型暂停主动展示，真正深眠才冻结冷落时钟。
- SQLite 无结构变化、无 SQL 迁移。原累计冷落秒数和已有生气/安抚进度保留；无法从旧版记录追溯真正最后一次鼠标触摸。需要全新计时可主动关闭再开启冷落功能。
- 旧自定义形象继续优先保留。缺少新动作会明确提示；想使用新素材，请主动恢复内置形象，不要删除旧资源目录。

## 真实完成范围

请先读 [逐项状态与缺失素材](docs/FEATURE_STATUS_V0.4.1.md)。本轮新增 **140 张独立 WebP 关键帧**，总计 **252 张**；四边姿态不是同一图旋转。素材属于生成式初版，角色大体保持同一服装/毛色/挂饰，但帧间比例、边缘和衔接仍需美术精修。尚缺独立倒挂、毛线球专属收尾和逐帧精确命中标定，不能将初版关键姿态称为专业流畅动画。
