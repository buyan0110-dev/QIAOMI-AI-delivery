# 安装、构建与 Windows 11 验收

## 安全升级与启动

1. 从原托盘“退出敲咪”，确认旧 Python/EXE 已结束。将新 ZIP 完整解压至新目录，不要在 ZIP 内直接运行。
2. 保留现有 `%LOCALAPPDATA%\QIAOMI AI`（或自己指定的 `QIAOMI_DATA_DIR`）。不要删除旧模型、`qiaomi.db`、语音与个人配置；如旧安装使用自定义数据目录，启动新版本时继续指定同一目录。
3. 第一次运行 `start.bat` 准备虚拟环境/依赖，它是调试入口，会有控制台。日常双击 `start.vbs` 或用 `install_shortcut.vbs` 创建桌面快捷方式，使用 pythonw 无控制台入口。语音依赖沿用原安装流程/`install_voice.bat`，新陪伴系统无需新增模型。
4. 首次升级会在原数据目录 `backups/pre-v0.6.0-*` 保存 JSON 与 SQLite 在线快照；日志在原数据目录 logs。新收藏/相册/布置为独立 `companion.db`，不迁移或覆盖长期记忆表。
5. 如要回滚，先退出新版本，再运行旧源码。旧版会忽略新增 sidecar；如确需回滚数据，先保留当前数据副本，再手动恢复所需备份文件，不能在运行时覆盖数据库。

## Windows 构建

需要 Windows x64 + Python3.12，执行 `build_windows.bat`。PyInstaller `qiaomi.spec` 保留 `console=False`，收集 qiaomi/PySide6/本地语音依赖与 assets，不收集用户数据目录、Ollama、模型或虚拟环境。输出 `dist/QIAOMI-AI/QIAOMI-AI.exe` 及完整 portable ZIP；必须分发整个文件夹/ZIP，不能只复制单个 EXE。当前 Linux 未完成 Windows 构建，脚本通过静态检查不等于 EXE 已成功产出。

## 必须由 Windows 11 用户逐项实测（当前均待验证）

- 正常双击 GUI 图标，无瞬时黑窗；不强制打开聊天窗口；小猫和托盘正常；重复启动只激活同一实例。
- 聊天右上角最小化/最大化/还原/关闭仍为粉色背景，关闭只隐藏；托盘可恢复/退出，Explorer 重启后恢复图标；自启动可开关。
- 普通模式鼠标靠近后追视，远离停止；摸头、耳朵、四爪、肚子、尾巴以及拖拽优先；透明空白区域不拦截其他应用。
- 原独立四摸：设置闷气后分开摸四次，依次生气/心软/蹭蹭/和好；快速连点不可替代。新模仿/回来事件不能清除闷气或计数。
- 开关旧“梦话”、旧“气泡”、新 F03、减少动画、不打扰，分别验证睡眠梦泡是否停止及恢复；醒来/摸猫即清除。
- 普通电脑无输入 15 分钟后操作鼠标，验证回来提醒；1 小时冷却；全屏时抑制；只读取闲置时长。
- 猜肉垫/拖毛线球/抛小鱼均可玩，连续开始无重复窗口；Esc/关闭/120 秒超时/摸猫均结束；不扣生活数值。
- 7 类收藏计数合并；相册开关/删除/清空/JSON 导出正常；重启后首次卡不重复；关闭记录不阻止物品入箱。
- 8 家具分主/小槽位，应用后重启保留；桌面默认无家具，道具开关有效；四边栖息和命中区域不变。
- 三主题、100/110/125/150%、不同窗口大小、多屏/物理 DPI：文字和按钮可滚动到达，图片比例正常。
- 喂食/洗澡所有阶段、脱睡衣/穿回、妈妈帮洗、三旧玩具、自动照顾、10/20/30分钟冷落、长期记忆/聊天正常；HyperX WASAPI、CPU int8 Whisper、TTS 正常。
- 小游戏/录音/动作中进入游戏模式：全部停止并隐藏，无新增定时器/模型活动；等待/移动鼠标/打开新页面不能唤醒；只能从托盘手动唤醒，播放旧重逢且不叠加普通回来提醒、不补跑事件。
- 游戏中用任务管理器测 CPU/内存/GPU 与升级前对比，含 APEX/幻兽帕鲁；退出托盘后无遗留进程、麦克风释放；重启应用旧记忆仍在。
